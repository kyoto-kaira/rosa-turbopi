# 外部ROSインターフェース

| 用途 | トピック | 型 | 状態 |
|---|---|---|---|
| バッテリー | `/ros_robot_controller/battery` | `std_msgs/msg/UInt16` | 実機で購読 |
| 速度指令 | `/cmd_vel` | `geometry_msgs/msg/Twist` | モックのみ・実機送信は未実装 |

設定例の名前と型は手元の環境で確認したものです。手元の実機ではrosbridge接続とバッテリー購読を確認済みです。日本語からのLLM経由呼び出しも利用者が確認しています。ほかの機体での動作を保証するものではありません。バッテリーの単位・尺度は未確認で、初期版は生値だけを返します。

アプリの開始・終了サービスは仕様確認後に追加します。ベンダー実装を転載せず、利用者が持つ環境の公開可能な接続仕様のみ記載してください。

## モックの速度指令

`MockTransport` はTwist形式の辞書をメモリに記録します。`/cmd_vel` というログ表記は模擬の送信先を示し、ROSやWebSocketへ送信しません。vx正は前進、vy正は左横移動、wz正は反時計回りです。距離・角度の測定や達成判定は行いません。

モックのバッテリー値は固定の `7400` です。実測値と混同しないようバックエンドを確認してください。

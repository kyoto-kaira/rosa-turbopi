# 外部ROSインターフェース

| 用途 | トピック | 型 | 状態 |
|---|---|---|---|
| バッテリー | `/ros_robot_controller/battery` | `std_msgs/msg/UInt16` | 初期版で購読 |
| 速度指令 | `/cmd_vel` | `geometry_msgs/msg/Twist` | 将来対応 |

設定例の名前と型は手元の環境で確認したものです。rosbridge経由の疎通は未確認です。バッテリーの単位・尺度は未確認で、初期版は生値だけを返します。

アプリの開始・終了サービスは仕様確認後に追加します。ベンダー実装を転載せず、利用者が持つ環境の公開可能な接続仕様のみ記載してください。
